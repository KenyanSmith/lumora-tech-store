## Current checkout
CreatorStick™ uses the Stripe Sandbox Payment Link configured in `app.js`.
Do not switch the link to live until Stripe activation/verification is complete.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload all files in this folder to the repository root.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. GitHub Pages will publish the static site. Changes can take several minutes.

Before public launch:
- Replace the Stripe sandbox URL with the live Payment Link.
- Verify all product prices/shipping with CJdropshipping.
- Publish the final returns/refund policy.
- Add a real support email/domain.
- Test the live checkout and fulfillment workflow.
